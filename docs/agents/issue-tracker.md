# Issue tracker: GitHub

Issues and PRDs for this repository live in GitHub Issues for
`Blawby/blawby-ai-chatbot`. Use the `gh` CLI and specify
`--repo Blawby/blawby-ai-chatbot` so operations target the canonical repository
rather than a fork remote.

## Conventions

- Create an issue with `gh issue create`.
- Read an issue with `gh issue view <number> --comments`.
- List issues with `gh issue list`, using suitable label and state filters.
- Comment with `gh issue comment <number>`.
- Apply or remove labels with `gh issue edit <number>`.
- Close issues with `gh issue close <number>`.
- Include `--repo Blawby/blawby-ai-chatbot` in each command.

## Skill terminology

When a skill says “publish to the issue tracker,” create a GitHub issue.

When a skill says “fetch the relevant ticket,” read the corresponding GitHub
issue and its comments.
